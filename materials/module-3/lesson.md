## Три режима Claude: карта на один экран

:::lead
Claude — не один инструмент, а три. В Chat ты думаешь и пишешь вместе с ним. В Cowork он сам работает с файлами на твоём компьютере. В Claude Code он собирает сайт, скрипт или мини-приложение по твоему описанию. Сегодня разбираемся, когда какой режим включать, и уходим с созвона с готовыми результатами в каждом.
:::

Большинство людей пользуются Claude как умным поисковиком: спросили, получили ответ, закрыли вкладку. Это примерно 10% того, что он умеет. Остальные 90% появляются, когда ты перестаёшь задавать вопросы и начинаешь **ставить задачи**, как новому сотруднику: с контекстом, с материалами, с понятным результатом на выходе.

Главная мысль урока простая. Режим выбирается не по тому, «насколько сложная задача», а по тому, **что должно получиться в конце**:

- нужен текст, вывод, идея, разбор → **Chat**;
- нужно что-то сделать с твоими файлами (разложить, собрать, посчитать по десяткам документов) → **Cowork**;
- нужна работающая штука (страница, калькулятор, скрипт, бот) → **Claude Code**.

:::diagram modes Три режима Claude: что делает каждый и когда его включать
:::

### Задача → режим

| Задача | Режим | Почему |
|---|---|---|
| Пост, письмо клиенту, сценарий Reels | Chat + Project | Нужен текст в твоём тоне, Project помнит бренд |
| Разобрать договор аренды на 30 страниц | Chat | Один-два документа, нужен вывод и риски |
| Сравнить 3 КП поставщиков | Chat | Прикрепил файлы, получил таблицу сравнения |
| Выводы из выгрузки продаж за квартал | Chat (артефакт) | Таблица + график прямо в чате |
| Разложить 200 файлов в папке «Загрузки» | Cowork | Много файлов на компьютере, многошаговая работа |
| Собрать отчёт из 15 документов в папке | Cowork | Claude сам открывает файлы и сохраняет итог |
| Лендинг для новой услуги | Claude Code | Нужна страница, которую можно открыть и опубликовать |
| Скрипт: почистить базу клиентов от дублей | Claude Code | Повторяемая операция с таблицей |
| Калькулятор стоимости для сайта | Артефакт или Claude Code | Простой — артефакт, для сайта — Code |

:::tip Если сомневаешься
Начни с Chat. Опиши задачу и спроси прямо: «В каком режиме Claude это лучше сделать: Chat, Cowork или Claude Code?» Он подскажет сам. Ошибка выбора стоит пять минут, а не день.
:::

## Claude Chat и Projects: второй мозг для текстов и документов

:::lead
Chat — это рабочий стол, а не окно вопросов. Сюда несут длинные документы, таблицы, черновики и сложные решения. Сила Claude в Chat — он внимательно читает большие тексты и спокойно рассуждает, не теряя деталей.
:::

### Длинные документы и глубокий анализ

Claude хорошо держит в голове большие объёмы: договор на десятки страниц, годовой отчёт, переписку, презентацию конкурента. Прикрепляешь файл (PDF, Word, Excel, CSV, картинку, скриншот) и ставишь задачу.

Разница между слабым и сильным запросом огромная:

- слабо: «Посмотри договор»;
- сильно: «Я арендатор. Найди пункты, где меня могут оштрафовать или выселить раньше срока. Процитируй каждый пункт, объясни простыми словами и предложи, как переписать».

Во втором случае Claude знает, **чью сторону он держит**, **что ищет** и **в каком виде отдать результат**. Это три вещи, которые стоит указывать всегда.

:::example Предприниматель из Астаны и договор аренды
Владелица кофейни получила от арендодателя договор на 24 страницы. Раньше она отправляла его знакомому юристу и ждала неделю. Теперь сначала прогоняет через Claude: за 3 минуты получает список из 7 рисков с цитатами, видит, что индексация аренды «по усмотрению арендодателя» не ограничена, и идёт к юристу уже с конкретными вопросами. Консультация занимает 20 минут вместо двух часов.
:::

Что ещё стоит включать в Chat:

- **Режим глубокого размышления.** В настройках чата есть опция, при которой Claude дольше думает перед ответом. Включай для анализа, расчётов, стратегий, сложных решений. Для поста в соцсети не нужно.
- **Поиск в интернете.** Если задача требует свежих данных (цены конкурентов, новости отрасли), включи веб-поиск и проси указывать источники.
- **Работа с таблицами.** Claude умеет посчитать по выгрузке: средний чек, динамику по месяцам, топ товаров. Проси показать, как он считал, и сверяй 2-3 цифры вручную.

:::warn Проверяй цифры и юридические выводы
Claude может ошибиться в расчёте или неверно понять пункт. Правило: всё, что влияет на деньги и подписи, проверяй по первоисточнику. Проси «ссылайся на номер пункта» и «укажи, из какой строки таблицы взята цифра» — так проверка занимает минуты.
:::

### Projects: Claude, который уже знает твой бизнес

Самая недооценённая функция. **Project** — отдельное пространство внутри Chat, где лежат:

1. **Инструкции** — кто ты, что продаёшь, кому, каким тоном говоришь, чего нельзя.
2. **Файлы** — прайс, описание услуг, лучшие отзывы, примеры удачных постов, регламенты.

Каждый новый чат внутри проекта уже знает всё это. Не нужно каждый раз начинать с «Я владелец стоматологии в Алматы, мы делаем...».

Удачные проекты для бизнеса:

- **«Маркетинг»** — тон бренда, оффер, примеры постов, портрет клиента. Здесь пишутся посты, рассылки, сценарии.
- **«Продажи»** — прайс, частые возражения, скрипты, кейсы. Здесь готовятся КП и ответы клиентам.
- **«Документы»** — шаблоны договоров, реквизиты, внутренние правила. Здесь разбираются входящие договоры.
- **«Команда»** — регламенты, должностные инструкции. Здесь пишутся вакансии и инструкции для новичков.

:::tip Правило одного проекта
Один проект = одна область работы. Не складывай всё в один «Мой бизнес»: чем точнее контекст, тем точнее ответы. И обновляй файлы: прайс прошлого года даст ответы прошлого года.
:::

## Артефакты: результат, а не простыня текста

:::lead
Артефакт — это готовая вещь, которую Claude показывает отдельно от переписки, обычно в панели справа или поверх чата на телефоне. Документ, таблица, схема, презентация или даже работающая мини-страница с кнопками.
:::

Когда ты просишь «сделай таблицу сравнения», «нарисуй схему процесса» или «собери калькулятор», Claude создаёт артефакт. С ним можно:

- **править словами** — «добавь колонку с доставкой», «сделай кнопки крупнее»;
- **переключаться между версиями** — если новая хуже, вернись к прошлой;
- **скачать или скопировать** — и вставить в документ или отправить коллеге;
- **поделиться** — в некоторых аккаунтах артефакт можно открыть по ссылке.

Что удобно делать артефактами:

| Что | Пример запроса |
|---|---|
| Таблица сравнения | «Сравни эти 3 КП по цене, срокам, гарантии и оплате» |
| Схема процесса | «Нарисуй схему: заявка → звонок → замер → договор → монтаж» |
| Калькулятор | «Калькулятор стоимости ремонта: площадь, тип работ, итог в тенге» |
| Мини-лендинг | «Одностраничник для акции на 8 марта» |
| Чек-лист | «Чек-лист открытия смены для бариста, с галочками» |

:::example Калькулятор за 10 минут
Мастерская по пошиву штор в Караганде каждый день считала стоимость вручную: ширина окна, ткань, тип карниза, монтаж. Один запрос в Chat — и у менеджера артефакт-калькулятор: вводит размеры, выбирает ткань из списка, сразу видит итог. Если его захочется встроить на сайт, это уже задача для Claude Code.
:::

Граница простая: **артефакт живёт внутри Claude**. Как только нужна отдельная страница со своим адресом, форма заявок, сохранение данных или регулярный запуск — переходим в Claude Code.

## Cowork: Claude работает с файлами на твоём компьютере

:::lead
Cowork — режим в приложении Claude для компьютера. Ты даёшь Claude доступ к конкретной папке и задачу, а он сам открывает файлы, читает, сортирует, создаёт новые документы и отчитывается. Это уже не диалог, а поручение.
:::

### Чем Cowork отличается от Chat

В Chat ты сам загружаешь каждый файл и сам сохраняешь результат. В Cowork Claude **сам ходит по папке**: открывает 40 PDF, вытаскивает из них данные, складывает в таблицу и сохраняет её рядом. Задача из десяти шагов выполняется одним поручением.

Типичные задачи:

- разобрать «Загрузки» или «Рабочий стол» по подпапкам и переименовать файлы по шаблону;
- собрать из папки со сканами счетов таблицу: дата, поставщик, сумма;
- сделать из заметок, таблиц и фото отчёт для клиента или презентацию;
- сравнить все договоры в папке и выписать сроки окончания;
- подготовить из папки с резюме короткую таблицу кандидатов.

:::example Автосервис и папка со счетами
Владелец автосервиса в Шымкенте каждый месяц сводил счета поставщиков запчастей: 60-80 PDF, ручной ввод в Excel, полдня работы. В Cowork одно поручение: «Пройди по папке, вытащи дату, поставщика, сумму и номер счёта, сохрани в таблицу, отдельно выпиши счета без номера». Claude сделал за 15 минут, владелец проверил выборочно 10 строк — расхождений нет. Полдня превратились в полчаса вместе с проверкой.
:::

### Как работать безопасно

Cowork действует на твоём реальном компьютере. Поэтому правила простые, но обязательные:

1. **Сначала копия.** Создай папку «Claude-тест» и положи туда копии файлов. Первые задачи — только на ней.
2. **Сначала план.** Проси: «Покажи план и дождись моего подтверждения». Читаешь план — потом разрешаешь.
3. **Ничего не удалять.** Пиши прямо: «Ничего не удаляй. Сомнительное складывай в папку "Проверить"».
4. **Отчёт в конце.** Проси файл-отчёт: что сделано, что куда перемещено, что не получилось.
5. **Читай запросы на разрешение.** Когда Claude спрашивает «можно?», смотри, какую папку и какое действие он затрагивает.

:::warn Доступность режима
Cowork — новый режим, он развивается быстро: интерфейс и доступность на разных тарифах и системах могут меняться. Если в твоём приложении его нет, проверь обновление приложения и раздел помощи на support.claude.com. Пока режима нет, многие задачи делаются в Chat, просто файлы загружаешь вручную.
:::

## Claude Code для не-программиста

:::lead
Claude Code — агент-разработчик. Ты описываешь словами, что нужно, а он создаёт файлы, пишет код, запускает и показывает результат. Тебе не нужно знать программирование. Нужно уметь сделать то, что ты и так умеешь как предприниматель: чётко поставить задачу и принять работу.
:::

Claude Code работает в нескольких местах: в браузере (claude.ai/code), в приложении Claude для компьютера и в терминале. Для старта проще всего браузер или приложение — ничего настраивать не нужно.

### Как поставить ТЗ

Claude Code делает ровно то, что понял. Хорошее ТЗ отвечает на шесть вопросов:

1. **Что делаем** — одностраничный сайт, калькулятор, скрипт для таблицы.
2. **Для кого** — кто будет пользоваться и с какого устройства (чаще всего с телефона).
3. **Зачем** — какое действие должен сделать человек: оставить заявку, написать в WhatsApp, посчитать цену.
4. **Что внутри** — список блоков или шагов.
5. **Как выглядит** — стиль, цвета, 1-2 примера сайтов, которые нравятся.
6. **Как проверим** — «готово, если открывается на телефоне, кнопка ведёт в WhatsApp, цены совпадают с прайсом».

Шестой пункт — самый важный и самый редко используемый. Когда у Claude есть понятный критерий «готово», он сам проверяет свою работу, а не просто сообщает «сделано».

:::tip Сначала план, потом код
Всегда начинай с фразы: «Сначала покажи план, ничего не делай, пока я не подтвержу». В Claude Code есть и специальный режим планирования. План читается за минуту, и в нём сразу видно, если Claude понял задачу не так. Исправить план — 30 секунд, исправить готовый сайт — полчаса.
:::

### Цикл работы: описал → сделал → проверил → уточнил

Никто не получает идеальный сайт с первого запроса — ни с программистом, ни с ИИ. Нормальный рабочий ритм — 3-5 кругов правок.

:::diagram cycle Цикл работы с Claude: каждый круг делает результат точнее
:::

Как проверять, не будучи программистом:

- **Открой и потыкай.** Нажми каждую кнопку, заполни форму, открой на телефоне.
- **Сверь с ТЗ.** Пройдись по пунктам «готово, если» как по чек-листу.
- **Попроси Claude объяснить.** «Объясни простыми словами, что ты сделал и что может сломаться».
- **Попроси Claude проверить себя.** «Проверь страницу на телефонной ширине экрана и перечисли проблемы».

Как давать правки:

- **Одна правка — одна мысль.** Не «переделай всё», а «заголовок крупнее, кнопку сделай фиолетовой, блок отзывов перенеси выше цен».
- **Показывай, а не описывай.** Скриншот с проблемой работает лучше трёх абзацев.
- **Говори, что не трогать.** «Меняй только блок с ценами, остальное оставь как есть».

### Как не сломать

Принцип, которому учат хороших разработчиков: **меняй только то, что просили**. Попроси Claude работать так же:

- просить минимальные изменения: «Сделай самое простое решение, которое работает. Без лишних функций»;
- сохранять версии: «Сохраняй версию проекта перед каждым большим изменением, чтобы можно было откатиться» — в Claude Code для этого обычно используют git, Claude настроит его сам;
- не давать доступ к лишнему: работай в отдельной папке проекта, а не на всём компьютере;
- **никогда не вставлять в чат пароли, токены и ключи доступа.** Спроси Claude, куда их положить безопасно, и вставь сам.

:::warn Остановиться — нормально
Если видишь, что Claude пошёл не туда, останови его (в интерфейсе есть кнопка остановки) и скажи, что не так. Лучше прервать на второй минуте, чем разбирать результат десяти минут работы не в ту сторону.
:::

### Мини-сайт за вечер: реальный сценарий

1. **15 минут — ТЗ.** Пишешь в Chat свободным текстом о бизнесе и просишь: «Сделай из этого ТЗ для лендинга по шести пунктам». Правишь.
2. **5 минут — план.** Отдаёшь ТЗ в Claude Code, читаешь план, подтверждаешь.
3. **10 минут — первая версия.** Claude собирает страницу, ты открываешь превью.
4. **40 минут — 3-5 кругов правок.** Тексты, цвета, порядок блоков, кнопка WhatsApp, фото.
5. **20 минут — проверка и публикация.** Чек-лист на телефоне, потом просишь: «Объясни пошагово, как опубликовать этот сайт бесплатно». Простые варианты — сервисы, куда сайт загружается перетаскиванием папки.

:::example Онлайн-школа английского
Преподаватель из Павлодара запускала летний интенсив. Вместо заказа сайта за несколько недель — вечер в Claude Code: первый экран с оффером, программа по неделям, отзывы учеников, цены и кнопка записи в WhatsApp. Утром ссылка уже стояла в профиле Instagram. Через месяц она добавила блок с расписанием — одной правкой за 10 минут.
:::

## CLAUDE.md и скиллы: научи Claude своим правилам

:::lead
Хороший сотрудник не переспрашивает каждый день, какой у вас тон и какие цвета у бренда. Claude тоже может помнить — если записать правила в файл. Для этого есть CLAUDE.md и скиллы.
:::

### CLAUDE.md — правила проекта

**CLAUDE.md** — обычный текстовый файл в папке проекта. Claude Code читает его в начале каждой работы. Это как Project-инструкции, только для Claude Code.

Что туда писать:

- **о проекте** — что это за сайт или инструмент, для кого;
- **стиль** — цвета, шрифты, тон текстов, обращение на «ты» или «вы»;
- **правила работы** — «сначала план», «меняй только то, что прошу», «объясняй простыми словами»;
- **запреты** — «не удаляй файлы без подтверждения», «не добавляй новые библиотеки без спроса»;
- **проверка** — «перед тем как сказать "готово", проверь на телефонной ширине».

Создать файл можно двумя способами: попросить Claude «создай CLAUDE.md с этими правилами» или дать ему самому изучить проект и предложить черновик (в Claude Code для этого есть команда `/init`). Главное — держать файл коротким: 10-30 строк правил работают лучше трёх страниц.

:::tip Растущий CLAUDE.md
Каждый раз, когда ты поправляешь Claude одним и тем же замечанием во второй раз, добавляй это в CLAUDE.md. Через месяц файл превращается в инструкцию, которая экономит десятки правок.
:::

:::diagram project Как устроен проект в Claude Code: правила, умения и файлы работают вместе
:::

### Скиллы — готовые умения

**Скилл** — это папка с инструкцией (файл `SKILL.md`), а иногда с шаблонами и примерами, которая учит Claude делать конкретную вещь по-твоему. Например: «как мы пишем коммерческие предложения», «как оформляем отчёт для клиента», «как готовим пост в наш Telegram-канал».

Как это работает:

1. В начале скилла пишется **название и описание** — когда его применять. Claude видит только эти пару строк, пока задача не подходит.
2. Когда задача подходит («сделай КП для клиента»), Claude открывает весь скилл и работает по нему.
3. Внутри — шаги, правила, примеры удачного результата, шаблоны.

Разница с CLAUDE.md: **CLAUDE.md — правила одного проекта, всегда включены. Скилл — умение под конкретный тип задачи, включается, когда нужно**, и его можно использовать в разных проектах. Скиллы поддерживаются и в Chat, и в Cowork, и в Claude Code — в настройках есть раздел, где их можно включить или загрузить свои.

:::example Скилл «КП в нашем стиле»
Агентство событийного маркетинга в Алматы собрало скилл: структура КП из 6 блоков, тон, обязательные условия оплаты, 2 примера удачных КП. Теперь менеджер пишет «КП на корпоратив для 80 человек, бюджет [сумма]», и Claude выдаёт документ в фирменной структуре. Раньше каждый менеджер писал КП по-своему.
:::

Как написать свой первый скилл: не пиши с нуля. Сделай задачу один раз вместе с Claude в чате, доведи результат до идеала, а потом попроси: «Упакуй то, как мы это сделали, в скилл: название, описание, когда применять, шаги и пример». Коротко и по делу — Claude и так умный, скилл должен содержать только то, чего он не знает о твоём бизнесе.

## Практика на созвоне

Работаем на твоих реальных материалах. Подготовь до созвона: один документ для разбора (договор, отчёт, КП), 2-3 файла о бизнесе (прайс, описание услуг, отзывы) и идею небольшой страницы или инструмента.

:::steps
1. Карта задач — выписываем 3 рутины из твоей недели и распределяем их по режимам Chat / Cowork / Code
2. Разбор документа в Chat — прикрепляем твой документ, ставим задачу с ролью, стороной и форматом ответа, проверяем 2-3 вывода по тексту
3. Project под бизнес — создаём проект, пишем инструкции (кто ты, клиент, тон, запреты), загружаем файлы, сравниваем ответ в проекте и без него
4. Артефакт — просим таблицу сравнения или калькулятор, правим его двумя-тремя репликами
5. Cowork на копии — создаём папку с копиями файлов, даём поручение «план → подтверждение → действие → отчёт», читаем разрешения
6. ТЗ для Claude Code — собираем ТЗ по шести пунктам, включая «готово, если»
7. Мини-лендинг — Claude показывает план, мы подтверждаем, получаем первую версию и делаем 3 круга правок
8. Проверка на телефоне — проходим чек-лист, просим Claude объяснить, что он сделал и как опубликовать
9. CLAUDE.md — записываем 5-10 правил проекта и проверяем, что Claude их соблюдает в следующей правке
:::

## Промпт-библиотека

Всё в [квадратных скобках] замени на своё. Промпты можно хранить в заметках или прямо в инструкциях Project.

:::prompt Разбор договора (Chat)
Ты опытный юрист по договорам в Казахстане. Я прикрепил договор [тип: аренды / оказания услуг / поставки].
Я выступаю стороной: [арендатор / заказчик / исполнитель].

Сделай:
1. Суть договора в 5 пунктах простым языком.
2. Риски для меня: штрафы, односторонние изменения, досрочное расторжение, скрытые платежи. По каждому — цитата и номер пункта.
3. Все сроки и даты в одной таблице.
4. Что стоит переписать: старая формулировка → новая формулировка.
5. 5 вопросов, которые нужно задать второй стороне.

Если чего-то в договоре нет, так и напиши, не додумывай. Это не замена юристу: отметь пункты, которые точно стоит показать специалисту.
:::

:::prompt Анализ таблицы продаж (Chat)
Я прикрепил выгрузку продаж за [период] из [CRM / кассы / Excel]. Колонки: [дата, товар, сумма, менеджер, канал].
Мой бизнес: [описание в одну строку].

Сделай:
1. Главные цифры: выручка, средний чек, количество продаж по месяцам.
2. Топ-5 и анти-топ-5 товаров по выручке.
3. Какой канал приносит больше всего денег и какой падает.
4. 3 неочевидные закономерности.
5. 3 конкретных действия на следующий месяц.

Покажи итог артефактом: таблица + график. Для каждой ключевой цифры напиши, как ты её посчитал, чтобы я мог проверить.
:::

:::prompt Инструкции для Project
Ты помощник по [маркетингу / продажам / документам] компании [название].
Мы: [что продаём] для [кого] в [город].
Наше отличие: [1-2 предложения].
Тон: [дружелюбный / экспертный / спокойный премиальный], обращение на «[ты / вы]».
Языки: русский, при необходимости казахский.
Нельзя: [запретные обещания, слова, темы, упоминание конкурентов].

Опирайся на файлы проекта: прайс, описание услуг, отзывы, примеры текстов.
Если данных не хватает, задай уточняющий вопрос, а не выдумывай.
Формат: коротко, структурно, готово к отправке клиенту.
:::

:::prompt Сравнение КП поставщиков (Chat, артефакт)
Я прикрепил [число] коммерческих предложения от поставщиков [чего].
Сделай таблицу-артефакт: цена, сроки, условия оплаты, гарантия, доставка, что не включено.
Под таблицей:
- кто выгоднее по итоговой стоимости с учётом скрытых расходов;
- красные флаги в каждом КП;
- 3 вопроса каждому поставщику перед решением.
Мой приоритет: [цена / сроки / надёжность].
:::

:::prompt Калькулятор-артефакт (Chat)
Сделай артефакт: калькулятор стоимости [услуги] для менеджера.
Поля: [например: площадь в м², тип работ из списка, срочность да/нет].
Цены: [перечисли тарифы и правила расчёта].
Итог в тенге крупно, ниже расшифровка, из чего сложилась сумма.
Простой дизайн, крупные кнопки, удобно на телефоне.
:::

:::prompt Разбор папки (Cowork)
Работаешь в выбранной папке. Там мои рабочие файлы вперемешку.
1. Изучи все файлы и предложи структуру подпапок.
2. Покажи план и дождись моего подтверждения. До подтверждения ничего не меняй.
3. После подтверждения разложи файлы и переименуй по шаблону [дата_тип_контрагент].
4. Ничего не удаляй. Дубликаты и непонятные файлы сложи в папку «Проверить».
5. В конце создай файл «отчет.md»: что куда перемещено и что вызвало сомнения.
:::

:::prompt Отчёт из документов (Cowork)
В папке [название] лежат [счета / акты / отчёты менеджеров] за [период].
Пройди по всем файлам и собери таблицу Excel: [дата, контрагент, сумма, номер документа, статус].
Отдельным листом выпиши файлы, из которых не удалось достать данные, и почему.
В конце дай сводку: итог по сумме, топ-5 контрагентов, странности, которые стоит проверить.
Сохрани таблицу в эту же папку. Исходные файлы не меняй.
:::

:::prompt ТЗ на лендинг (Claude Code)
Сделай одностраничный сайт для [бизнес, город].
Для кого: [кто клиенты], заходят в основном с телефона.
Цель: человек нажимает кнопку [записаться в WhatsApp / оставить заявку].
Блоки по порядку: первый экран с оффером «[оффер]», 3 преимущества, услуги и цены [список], отзывы [вставлю тексты], частые вопросы, контакты и карта.
Стиль: [минимализм / премиум / ярко], цвета [цвета], шрифт читаемый.
Готово, если: страница открывается на телефоне без горизонтальной прокрутки, все кнопки ведут в WhatsApp [номер вставлю сам], цены совпадают с моим списком, нет текста-заглушки.

Работай так: сначала покажи план и дождись подтверждения. Самое простое решение, без лишних функций. В конце объясни простыми словами, как открыть сайт и как опубликовать его бесплатно.
:::

:::prompt Шаблон CLAUDE.md
Создай в проекте файл CLAUDE.md с такими правилами:

# Проект
[Лендинг / калькулятор / скрипт] для [бизнес]. Пользователи: [кто], в основном с телефона.

# Стиль
Цвета: [цвета]. Шрифт: [шрифт или «читаемый, без засечек»]. Тексты: на «[ты / вы]», коротко, без канцелярита.

# Как работать
- Сначала план, потом изменения. Жди моего «ок».
- Меняй только то, что я прошу. Остальное не трогай.
- Самое простое решение, которое работает. Новые библиотеки — только с моего согласия.
- Перед большим изменением сохраняй версию, чтобы можно было откатиться.
- Объясняй, что сделал, простыми словами, без жаргона.

# Запреты
- Не удаляй файлы без подтверждения.
- Не вставляй пароли и ключи в код и не проси их в чат.

# Проверка
Перед словом «готово» проверь страницу на ширине телефона и пройди по всем кнопкам.
:::

:::prompt Упаковать работу в скилл
Мы только что сделали [КП / отчёт для клиента / пост], и результат мне нравится.
Упакуй этот процесс в скилл:
1. Название латиницей через дефис, например [kp-v-nashem-stile].
2. Описание в 2-3 предложениях: что делает скилл и в каких ситуациях его применять (с примерами фраз, на которые он должен срабатывать).
3. Шаги работы по порядку.
4. Правила: тон, структура, обязательные пункты, запреты.
5. Один пример удачного результата.
Пиши коротко: только то, что нужно знать о нашем бизнесе, общие вещи ты и так знаешь.
Оформи как папку со SKILL.md, чтобы я мог её загрузить.
:::

:::prompt Найди и исправь (Claude Code)
Проблема: [что не работает — например: на телефоне кнопка «Записаться» уезжает за край экрана].
Как воспроизвести: [открываю сайт с телефона, листаю до блока цен].
Ожидаю: [кнопка видна целиком и ведёт в WhatsApp].
Скриншот прикрепил.

Сначала найди причину и объясни её одной-двумя фразами. Потом предложи самое маленькое исправление и сделай его. Ничего другое не меняй. После исправления проверь, что проблема ушла и ничего рядом не сломалось.
:::

:::prompt Скрипт для таблицы (Claude Code)
У меня таблица [файл .xlsx / .csv] с колонками: [перечисли].
Нужен скрипт, который:
1. [например: убирает дубликаты клиентов по номеру телефона, номера приводит к виду +7XXXXXXXXXX];
2. [например: считает сумму покупок каждого клиента за последние 90 дней];
3. сохраняет результат в новый файл, исходный не трогает.
Я не программист. Сначала проверь скрипт на копии файла, покажи 5 строк результата до и после. Потом объясни по шагам, как мне запускать его самому каждый месяц.
:::

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| Каждый раз заново объясняешь, кто ты и чем занимаешься | Создай Project с инструкциями и файлами один раз |
| «Сделай красиво», «сделай сайт» | Цель, аудитория, блоки, стиль и критерий «готово, если» |
| Принимаешь первый ответ или бросаешь после первой неудачи | 3-5 кругов правок — нормальный рабочий ритм |
| Даёшь Cowork папку с оригиналами | Первые задачи только на копии, «ничего не удаляй» |
| Жмёшь «Разрешить» не читая | Смотри, какую папку и какое действие затрагивает Claude |
| Просишь сразу большое приложение с личным кабинетом | Маленькая рабочая версия, затем по одной функции |
| Десять правок в одном сообщении | Одна-три правки за раз и проверка после каждой |
| Веришь цифрам и юридическим выводам на слово | Проси номера пунктов и строк, сверяй ключевое |
| Вставляешь пароли, токены, ключи в чат | Спроси, куда их положить, и вставь сам |
| Одно и то же замечание даёшь в пятый раз | Запиши правило в CLAUDE.md или инструкции Project |
| Один бесконечный чат на все темы | Новая задача — новый чат; длинный чат теряет фокус |

## Чек-лист «готово, если»

- Ты за 10 секунд можешь сказать, в какой режим нести задачу: Chat, Cowork или Claude Code.
- У тебя есть Project с инструкциями о бизнесе и 2-3 файлами, и ответы в нём заметно точнее, чем без него.
- Ты разобрал реальный документ и проверил минимум 2 вывода по тексту первоисточника.
- Ты сделал хотя бы один артефакт и поправил его словами.
- Ты запустил задачу в Cowork на копии папки, прочитал план и получил отчёт.
- У тебя есть ТЗ по шести пунктам, включая критерий «готово, если».
- Твой мини-лендинг или скрипт работает: проверен на телефоне или на копии данных.
- В проекте лежит CLAUDE.md с правилами, и Claude их соблюдает.
- Ты понимаешь, чем скилл отличается от CLAUDE.md, и знаешь, какую свою задачу упакуешь в скилл первой.

## Глоссарий

| Термин | Что это простыми словами |
|---|---|
| Chat | Диалог с Claude на claude.ai или в приложении: тексты, анализ, документы |
| Project | Пространство в Chat с постоянными инструкциями и файлами, общими для всех чатов внутри |
| Артефакт | Готовый результат в отдельной панели: документ, таблица, схема, мини-страница |
| Cowork | Режим в приложении для компьютера: Claude сам выполняет многошаговую задачу с файлами в выбранной папке |
| Claude Code | Агент-разработчик: по описанию словами создаёт сайты, скрипты и мини-приложения |
| Контекст | Всё, что Claude видит в текущей работе: сообщения, файлы, инструкции |
| ТЗ | Техническое задание: что делаем, для кого, зачем, что внутри, как выглядит, как проверим |
| План | Описание шагов, которое Claude показывает до начала работы, чтобы ты подтвердил |
| Итерация | Один круг «сделал → проверил → уточнил» |
| CLAUDE.md | Файл с правилами проекта, который Claude Code читает в начале работы |
| Скилл | Папка с инструкцией SKILL.md: умение под конкретный тип задач, включается по ситуации |
| Разрешение | Запрос Claude «можно?» перед действием с файлами или командами |
| Превью | Предпросмотр сайта или страницы до публикации |
| Публикация (деплой) | Размещение сайта в интернете, чтобы он открывался по ссылке |
| Версия (git) | Сохранённое состояние проекта, к которому можно откатиться |
