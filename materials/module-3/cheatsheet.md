# Модуль 3 — Claude: Chat, Cowork & Code

У Claude три режима работы. В этом модуле разбираемся, какой режим брать под какую задачу. Тексты и анализ делаешь в Chat, файлы на компьютере разбирает Cowork, сайты и мини-приложения собирает Claude Code.

## Ключевые понятия

- **Chat** — обычный диалог с Claude на claude.ai или в приложении. Подходит для текстов, анализа, разбора длинных документов и мозгового штурма.
- **Projects (Проекты)** — отдельное пространство внутри Chat. В нём лежат твои постоянные инструкции и файлы, и каждый новый чат в проекте уже знает контекст: бренд, тон, продукт.
- **Артефакты** — готовый результат, который Claude показывает отдельно справа от чата: документ, таблица, схема или работающая мини-страница. Его можно править и скачивать.
- **Cowork** — режим в приложении Claude Desktop. Ты даёшь Claude доступ к папке на компьютере, и он сам выполняет многошаговую задачу с файлами: разбирает, переименовывает, собирает отчёт или презентацию.
- **Claude Code** — агент-разработчик. Описываешь словами, что нужно (сайт, скрипт, бот), а он пишет код, создаёт файлы и запускает их. Работает в терминале, в десктоп-приложении и в браузере (claude.ai/code).
- **Контекст** — всё, что Claude «видит» в текущем разговоре: твои сообщения, файлы, инструкции. Чем точнее контекст, тем лучше результат.
- **Разрешения** — в Cowork и Claude Code агент спрашивает подтверждение перед действиями с файлами или командами. Читай, что именно он собирается сделать, и только потом соглашайся.

### Когда какой режим брать

- **Контент** (посты, письма, сценарии, тексты для сайта) — Chat плюс Project с инструкциями по бренду.
- **Аналитика** (договоры, отчёты, сравнение документов, выводы из таблиц) — Chat для одного-двух файлов. Cowork, если файлов много и они лежат в папке на компьютере.
- **Продукт** (лендинг, калькулятор, бот, автоматизация таблиц) — Claude Code.

> Правило: нужно «подумать и написать» — бери Chat. Нужно «сделать что-то с моими файлами» — Cowork. Нужно «чтобы появилась работающая штука» — Claude Code.

## Пошагово

1. Зарегистрируйся на claude.ai через почту или Google-аккаунт.
2. Задай первый вопрос в Chat: прикрепи PDF или документ и попроси короткую сводку.
3. Создай Project: дай ему название, вставь инструкции (кто ты, твой продукт, тон общения) и загрузи 2-3 ключевых файла.
4. Открой новый чат внутри проекта и попроси написать пост или письмо. Сравни с ответом без проекта.
5. Скачай Claude Desktop с claude.com/download и войди в тот же аккаунт.
6. Создай на компьютере тестовую папку с копиями файлов (не с оригиналами!) и запусти в ней первую задачу Cowork.
7. Открой Claude Code (в вебе claude.ai/code или в десктоп-приложении) и попроси собрать простой одностраничный сайт.
8. Посмотри результат, напиши правки обычными словами («крупнее заголовок», «добавь блок с отзывами») и повтори.

## Готовые промпты

**Анализ договора (Chat)**

```
Ты опытный юрист по договорам. Я прикрепил договор [тип договора, например: оказания услуг].
Я выступаю стороной [заказчик/исполнитель].
Сделай:
1. Краткую суть договора в 5 пунктах.
2. Список рисков для меня с цитатами пунктов.
3. Сроки, штрафы и условия расторжения.
4. Что стоит переписать и как, с готовыми формулировками.
Пиши простым языком, без юридического жаргона.
```

**Сводка по нескольким документам (Chat)**

```
Я прикрепил [количество] документов на тему [тема].
Составь сводку:
- главные выводы по каждому документу (по 3 пункта);
- где документы совпадают и где противоречат друг другу;
- цифры и факты, которые важны для решения [какое решение принимаю].
В конце дай рекомендацию в 3-5 предложениях.
Если чего-то нет в документах, так и напиши, не додумывай.
```

**Инструкции для Project (вставить в настройки проекта)**

```
Ты помощник по маркетингу компании [название].
Мы продаём [продукт/услуга] для [целевая аудитория] в [город/страна].
Тон: [дружелюбный/экспертный/дерзкий], обращение на «[ты/вы]».
Нельзя: [запретные темы, слова, обещания].
Всегда опирайся на загруженные файлы: прайс, описание продукта, отзывы.
Если данных не хватает, задай уточняющий вопрос, а не выдумывай.
Формат ответа: коротко, структурно, готово к публикации.
```

**Разобрать папку (Cowork)**

```
В выбранной папке лежат мои рабочие файлы вперемешку.
1. Посмотри все файлы и предложи структуру подпапок (например: Договоры, Счета, Фото, Презентации).
2. Покажи план и дождись моего подтверждения.
3. После подтверждения разложи файлы и переименуй их по шаблону [дата_тип_клиент].
4. Ничего не удаляй. Дубликаты сложи в папку «Проверить».
5. В конце создай файл «отчет.md» со списком того, что куда переместил.
```

**Собрать отчёт или презентацию из файлов (Cowork)**

```
В папке [название папки] лежат материалы по проекту [название]: таблицы, заметки, фото.
Изучи их и собери:
1. Документ «Итоговый отчёт» на 1-2 страницы: цели, что сделано, цифры, выводы.
2. Презентацию на [количество] слайдов для [кому: клиент/инвестор/команда].
Сохрани оба файла в эту же папку. Цифры бери только из файлов и укажи, из какого файла каждая.
```

**Лендинг (Claude Code)**

```
Сделай одностраничный сайт-лендинг для [бизнес/услуга].
Аудитория: [кто клиенты]. Цель страницы: [заявка/звонок/запись в WhatsApp].
Блоки: первый экран с оффером, преимущества, услуги и цены [список], отзывы, частые вопросы, форма заявки.
Стиль: [минимализм/премиум/яркий], цвета [цвета бренда].
Сайт должен хорошо выглядеть на телефоне.
Сначала покажи план, потом сделай. В конце объясни простыми словами, как открыть сайт и как его опубликовать.
```

**Скрипт для таблицы (Claude Code)**

```
У меня есть таблица [файл .xlsx/.csv] с колонками: [перечисли колонки].
Напиши скрипт, который:
1. [например: убирает дубликаты по телефону];
2. [например: считает сумму продаж по каждому менеджеру за месяц];
3. сохраняет результат в новый файл, исходный не трогает.
Я не программист: объясни по шагам, как запустить скрипт, и сначала проверь его на копии файла.
```

**Telegram-бот (Claude Code)**

```
Сделай простого Telegram-бота для [бизнес].
Что он умеет:
- приветствует и показывает меню кнопками: [пункты меню];
- отвечает на частые вопросы: [вопросы и ответы];
- принимает заявку (имя, телефон, услуга) и присылает её мне в личку.
Токен бота я получу у @BotFather. Объясни, куда его вставить, не прося прислать его в чат.
Объясни пошагово, как запустить бота на компьютере и какие есть варианты, чтобы он работал постоянно.
```

## Частые ошибки

- Задаёшь одно и то же вступление в каждом новом чате → создай Project и один раз пропиши инструкции и файлы.
- Пишешь «сделай красиво» → указывай аудиторию, цель, формат, объём и пример желаемого результата.
- Запускаешь Cowork на папке с оригиналами → сначала тренируйся на копии и проси «ничего не удалять без подтверждения».
- Не читая жмёшь «Разрешить» на всё → смотри, какие файлы и команды затрагивает агент.
- Доверяешь цифрам и юридическим выводам без проверки → проси ссылки на конкретные пункты и файлы и сверяй ключевые моменты сам.
- Просишь в Claude Code сразу «большое приложение» → начни с маленькой рабочей версии и добавляй функции по одной.
- Вставляешь пароли и токены прямо в чат → храни их отдельно и спрашивай Claude, куда их положить безопасно.
