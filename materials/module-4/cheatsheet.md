# Модуль 4 — ИИ-агенты на Ductor

Здесь ты собираешь своего первого ИИ-агента в Telegram без программирования. Агент помнит контекст, работает с файлами и сам выполняет задачи по расписанию.

## Ключевые понятия

- **Чат vs агент**: чат отвечает на вопрос и забывает. У агента есть цель, инструменты и память, и он сам выполняет действия: создаёт файлы, ищет информацию, присылает отчёты.
- **Ductor** — no-code платформа. Она превращает ИИ-движок (Claude Code, Codex или Gemini CLI) в персонального агента в Telegram. У агента есть память, рабочая папка, расписание и фоновые задачи.
- **Файл инструкций** — текстовый файл (например, `CLAUDE.md`), который агент читает при каждом старте. В нём записаны роль, правила поведения, тон и запреты. Это «должностная инструкция» агента.
- **Память**: отдельный файл, куда агент записывает долгосрочные факты о тебе. Это твои предпочтения, решения и повторяющиеся задачи. Благодаря ему агент помнит тебя между разговорами.
- **Рабочая папка (workspace)** — личное пространство агента на сервере. Там лежат инструкции, память, инструменты и готовые файлы для тебя.
- **Cron (задача по расписанию)** — задание, которое агент запускает сам в заданное время. Например, каждое утро в 8:00 или по пятницам в 18:00. Важно, чтобы часовой пояс был задан правильно.
- **Вебхук** — «входящая дверь» для внешних сервисов. Например, пришла заявка с сайта, и агент сам её обрабатывает.
- **Фоновая задача и под-агент**: долгую работу агент отдаёт фоновому исполнителю и не перестаёт с тобой общаться. Под-агент — это отдельный бот со своей специализацией, памятью и чатом.

## Пошагово

1. Определи одну цель агента. Не «помощник во всём», а например «ассистент по контенту для моего бизнеса». Одна роль даёт лучший результат.
2. Создай бота в Telegram. Открой @BotFather, отправь команду `/newbot`, придумай имя и username (он должен заканчиваться на `bot`).
3. Получи токен бота. BotFather пришлёт длинную строку. Это ключ от твоего бота: сохрани его в менеджер паролей и никому не пересылай, даже преподавателю.
4. Установи Ductor по официальной инструкции на ductor.dev или в README на GitHub. Мастер настройки попросит токен бота, твой Telegram ID (чтобы бот отвечал только тебе) и выбор ИИ-движка.
5. Напиши боту первое сообщение и проверь, что он отвечает. Если бот молчит, проверь токен и разрешённых пользователей в настройках.
6. Задай роль. Отправь агенту промпт «Роль агента» из раздела ниже и попроси записать её в файл инструкций.
7. Добавь правила поведения: тон, формат ответов, что делать без спроса, а на что спрашивать подтверждение.
8. Расскажи о себе: бизнес, клиенты, стиль, цели. Попроси агента запомнить это по правилам памяти.
9. Проверь часовой пояс. Спроси агента: «Какой часовой пояс у тебя стоит?» Если он неверный, попроси поменять и перезапустить бота командой `/restart`.
10. Создай первую автоматизацию, например утренний дайджест. Опиши задачу словами, агент сам создаст cron. Он может уточнить модель и «тихие часы» (когда не беспокоить).
11. Дождись первого запуска и оцени результат. Что-то не так? Попроси агента поправить описание задачи. Создавать задачу заново не нужно.
12. Через неделю проведи ревизию: какие задачи полезны, какие отключить, что агенту стоит запомнить.

## Готовые промпты

**Описание роли агента**

```
Ты мой персональный ИИ-агент. Твоя роль: [например: ассистент по маркетингу и контенту].
Мой бизнес: [чем занимаюсь, ниша, город].
Мои клиенты: [кто они, их боли].
Твои главные задачи:
1. [задача 1]
2. [задача 2]
3. [задача 3]
Запиши это в свой файл инструкций как постоянную роль. Покажи итоговый текст.
```

**Инструкция поведения**

```
Добавь в свой файл инструкций правила поведения:
- Отвечай на «ты», коротко и по делу, без воды.
- Формат: удобно читать с телефона, списки вместо длинных абзацев.
- Если задача неясна, задай максимум 2 уточняющих вопроса.
- Перед удалением файлов, отправкой данных наружу и любыми платными действиями спрашивай подтверждение.
- Если не уверен в факте, так и скажи, не выдумывай.
- Язык ответов: [русский].
Покажи, что изменилось.
```

**Правила памяти**

```
Настрой правила своей памяти:
- Запоминай: мои предпочтения, решения, клиентов, повторяющиеся задачи, то, что я прошу запомнить.
- Не запоминай: разовые вопросы, временные данные, пароли, токены и любые ключи доступа.
- Записи короткие, с датой в формате ГГГГ-ММ-ДД.
- Если я говорю, что факт устарел, сразу обнови или удали его.
Сейчас запомни: [факт о себе / предпочтение].
```

**Утренний дайджест по расписанию**

```
Создай задачу по расписанию: каждый день в [08:00] по моему времени присылай утренний дайджест.
Содержание:
1. 3-5 главных новостей по теме [моя ниша] за последние сутки, по 1-2 строки, со ссылкой на источник.
2. Одна идея для поста на сегодня.
3. Напоминание о моих целях на неделю: [цели].
Объём: до 15 строк. Не присылай ничего с [22:00] до [07:00].
Перед созданием проверь мой часовой пояс.
```

**Регулярное напоминание**

```
Создай напоминание по расписанию: каждый [понедельник] в [10:00] спрашивай меня:
«Какие 3 главные задачи на эту неделю?»
Мой ответ сохраняй в память, а в [пятницу] в [17:00] присылай короткий итог: что из этого сделано.
```

**Еженедельный отчёт из файлов**

```
Каждую [пятницу] в [18:00] собирай отчёт по файлам в папке [название папки]:
что добавилось за неделю, краткая выжимка, 3 вывода и 1 рекомендация.
Готовый отчёт сохраняй файлом и присылай мне в чат.
```

**Проверка и правка cron-задачи**

```
Покажи список моих задач по расписанию: название, время, что делает.
Для задачи [название] измени: [время / содержание / тихие часы].
Задачу не пересоздавай, отредактируй описание существующей.
```

**Длинная задача в фоне**

```
Это займёт время, поэтому сделай в фоне: [например: найди 10 конкурентов в нише X в городе Y, их цены и сильные стороны].
Результат оформи списком и сохрани файлом. Пока работаешь, я продолжу писать тебе по другим вопросам.
```

**Аудит агента**

```
Проанализируй свой файл инструкций и память.
1. Что противоречит друг другу?
2. Что устарело?
3. Чего не хватает, чтобы ты был полезнее мне как [роль]?
Предложи изменения списком, без моего «ок» ничего не применяй.
```

## Частые ошибки

- Даёшь агенту роль «помогай во всём» → выбери одну конкретную роль и 3-5 задач, позже можно добавить под-агентов.
- Пересылаешь токен бота в чат, другу или «специалисту» → токен — это полный доступ к боту. Если он утёк, выпусти новый через @BotFather.
- Пишешь пароли и ключи в сообщения агенту «чтобы запомнил» → секреты храни в менеджере паролей. Агенту явно запрети записывать их в память.
- Дайджест приходит в 3 часа ночи → проверь часовой пояс агента и настрой «тихие часы».
- Удаляешь и создаёшь задачу заново из-за мелочи → проси агента отредактировать описание существующей задачи.
- Ждёшь, что агент «сам догадается» → всё важное (тон, формат, ограничения) должно быть в файле инструкций, а не только в одном сообщении.
- Ставишь сразу 10 автоматизаций → начни с одной, неделю оценивай пользу, потом добавляй следующую.
