# Что мы используем в студии с агентами

Это честный рассказ, как устроена работа с ИИ у нас в Yelumio AI Studio. Без секретов и внутренней кухни — только принципы и инструменты, которые ты сможешь повторить сам. Многое из этого разберём в модулях 3–5.

---

## 1. Главный инструмент — Claude и Claude Code

- **Claude** (чат) — тексты, разбор документов, Проекты с базой знаний под каждого клиента и задачу.
- **Claude Code** — агент, который работает не в окне чата, а с файлами и папками: читает материалы, пишет документы, собирает отчёты, делает сайты, запускает проверки. Ему можно поставить задачу на час работы и заниматься своими делами.
- ChatGPT и Gemini — как второе мнение, для картинок, голоса, работы внутри Google-сервисов.

**Почему так:** Claude аккуратно держит правила и стиль, а Claude Code позволяет перейти от «спросил — получил ответ» к «поручил — получил готовую работу».

## 2. У каждого агента есть «память и правила»

Каждый наш агент — это не просто чат. У него есть:

- **Файл правил** (`CLAUDE.md` / `AGENTS.md`): кто он, что делает, какой тон, что нельзя. Агент читает его в начале каждой работы.
- **Файл памяти**: агент сам дописывает туда устойчивые факты — предпочтения, решения, договорённости. Поэтому он «помнит» человека между разговорами.
- **Общая память** для всех агентов студии: факты, которые нужны всем (например, общие правила оформления).

Примеры таких файлов — `CLAUDE.md-example.md` и `AGENTS.md-example.md` в этом наборе.

### Свои скиллы студии
Под повторяющиеся задачи мы пишем свои: построение промптов для генерации изображений и видео, режиссура рекламных роликов, публикации в соцсети, оформление материалов. Принцип: **если задачу делаем больше трёх раз — она становится скиллом.**

В этом наборе — 7 скиллов, написанных по тем же принципам специально для предпринимателя (папка `skills/`).

## 4. Коннекторы (MCP) — агент подключён к рабочим сервисам

**MCP** — стандарт «розеток», через которые агент подключается к сервисам. У нас подключены:

| Коннектор | Для чего |
|---|---|
| **Notion** | Базы знаний, задачи, документация |
| **Google Drive** | Файлы клиентов и проектов |
| **Gmail** | Черновики писем, поиск в переписке |
| **Google Calendar** | Встречи, планирование |
| **Canva** | Дизайн-макеты |
| **Higgsfield** | Генерация изображений и видео |

**Правило:** агент может читать и готовить черновики, но **отправка наружу** (письмо, публикация, сообщение клиенту) — только после подтверждения человека.

В Claude коннекторы включаются в настройках (раздел «Коннекторы» / Connectors) — без программирования.

## 5. Агенты в Telegram

Часть наших агентов живёт в Telegram: пишешь боту как сотруднику — он делает работу и присылает результат файлом или сообщением. У каждого — своя специализация (контент, разработка, обучение и т.д.), своя память и правила. Агенты умеют передавать задачи друг другу.

## 6. Фоновые задачи и расписание

- **Фоновые задачи:** долгую работу (исследование, сборка отчёта, подготовка материалов) агент отдаёт «помощнику», который работает отдельно, а сам продолжает общаться. Результат приходит, когда готов.
- **Расписание (крон):** задачи, которые повторяются, запускаются сами — например, ежедневный пост, утренняя сводка, еженедельный отчёт.

## 7. Наши принципы работы с агентами

1. **Инструкции важнее модели.** Хорошо описанная задача на средней модели лучше плохой на топовой.
2. **Сначала план, потом работа.** Для больших задач агент показывает план.
3. **Проверка перед «готово».** Агент обязан проверить результат по задаче.
4. **Человек решает.** Деньги, отправка наружу, удаление — только с подтверждением.
5. **Никаких секретов в инструкциях.** Ключи и пароли хранятся отдельно и защищённо.
6. **Повторяется — автоматизируй.** Три раза сделал руками — сделай скилл или расписание.
