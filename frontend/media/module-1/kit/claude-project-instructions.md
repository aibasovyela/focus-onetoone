# Claude: Проекты, инструкции и Стили

В Claude есть три уровня настройки. Используй все три.

| Уровень | Где | Для чего |
|---|---|---|
| **Личные настройки (Personal preferences)** | Настройки → Профиль | Общее «о тебе» — действует во всех чатах |
| **Проект (Project)** | Левое меню → Проекты → Создать | Отдельная «папка» под одну тему: свои инструкции + свои файлы |
| **Стиль (Style)** | Кнопка выбора стиля под полем ввода | Как писать: тон, длина, манера |

> Названия пунктов меню могут отличаться — ищи по смыслу.

---

## 1. Что такое Проект

**Проект** — это рабочая папка в Claude. В ней:

- **Инструкции проекта** — правила, которые Claude читает в каждом чате этого проекта.
- **Знания проекта (Project knowledge)** — файлы, которые ты загрузил: прайс, описание компании, примеры текстов, регламенты. Claude опирается на них.
- Все чаты по этой теме лежат в одном месте.

**Какие проекты завести предпринимателю (начни с 2–3):**

1. **«Мой бизнес — маркетинг»** — посты, отзывы, рекламные тексты.
2. **«Документы и договоры»** — разбор договоров, письма, претензии.
3. **«Цифры и таблицы»** — выгрузки продаж, отчёты, финмодели.
4. **«Найм и команда»** — вакансии, интервью, регламенты.

## 2. Шаблон инструкций проекта

Скопируй в поле «Инструкции проекта» (Project instructions) и замени [скобки].

```xml
<роль>
Ты — [кто: опытный маркетолог / бизнес-аналитик / юрист-помощник] для компании [название].
Твоя задача в этом проекте: [одна фраза — например, «помогать писать тексты для соцсетей и отвечать на отзывы»].
</роль>

<о_компании>
Компания: [название], [сфера], [город/страна].
Продукт/услуги: [что продаём, 3–5 пунктов].
Клиенты: [кто, возраст, что для них важно].
Отличие от конкурентов: [1–3 пункта].
Тон бренда: [например: тёплый, уверенный, без пафоса, на «вы»].
</о_компании>

<как_работать>
1. Сначала опирайся на файлы в знаниях проекта. Если ответа в них нет — скажи об этом.
2. Если задача неясна — задай до 3 уточняющих вопросов, потом делай.
3. Давай 2–3 варианта, если речь о тексте или идее.
4. Отмечай, где факт из файлов, а где твоё предположение.
</как_работать>

<формат>
- Язык: русский. [Казахский — по запросу.]
- Сначала готовый результат, потом короткое пояснение.
- Абзацы короткие, удобно читать с телефона.
</формат>

<запреты>
- Не выдумывай цены, сроки, акции и факты о компании — бери только из файлов.
- Не используй слова: [список стоп-слов бренда, например «уникальный», «лучший на рынке»].
- Без смайликов, если я не попросил.
</запреты>
```

**Почему в тегах `<...>`:** Claude особенно хорошо понимает текст, разложенный по «коробочкам» с подписями. Теги можно называть как угодно, хоть по-русски. Это не код — просто разметка, чтобы модель не путала, где правила, а где данные.

### Какие файлы положить в знания проекта

- Описание компании (1–2 страницы): кто мы, что продаём, для кого.
- Прайс или меню (актуальное!).
- 5–10 примеров текстов, которые тебе нравятся (свои лучшие посты, письма).
- Частые вопросы клиентов и правильные ответы.
- Для проекта «Документы»: типовой договор компании, свои требования к договорам.

> **Не загружай:** пароли, паспортные данные и ИИН, банковские реквизиты клиентов, базы клиентов с телефонами. Подробнее — в `which-model-when.md`.

## 3. Пример: проект «Маркетинг кофейни»

```xml
<роль>
Ты — SMM-редактор и копирайтер сети кофеен «[Название]» в Алматы.
Помогаешь писать посты, сторис, ответы на отзывы и описания меню.
</роль>

<о_компании>
5 кофеен в спальных районах и у бизнес-центров. Свежая обжарка, десерты собственного производства.
Клиенты: офисные сотрудники 25–40 лет утром, мамы с детьми днём, студенты вечером.
Отличие: быстро (кофе за 3 минуты), своя выпечка каждое утро, программа лояльности в приложении.
Тон: дружелюбный, на «вы», с лёгким юмором, без канцелярита и пафоса.
</о_компании>

<как_работать>
1. Меню и цены — только из файла «menu.pdf» в знаниях проекта.
2. На отзывы: поблагодари, конкретно отреагируй на суть, предложи решение, подпишись «Команда [Название]».
3. На гневный отзыв: без оправданий, признать, извиниться, предложить связаться в WhatsApp [номер компании].
4. Посты: 3 варианта заголовка, текст до 600 знаков, призыв к действию в конце.
</как_работать>

<формат>
Русский язык. Результат сразу, без вступлений. Хэштеги — только если попрошу.
</формат>

<запреты>
Не обещать скидки и компенсации — это решает управляющий. Не спорить с клиентом. Слова «вкусняшка», «топ», «бомба» не использовать.
</запреты>
```

## 4. Стили (Styles)

**Стиль** — это манера письма Claude. Переключается кнопкой рядом с полем ввода (иногда в меню «Инструменты» или «+»). Встроенные обычно такие: **Обычный**, **Краткий**, **Объясняющий**, **Официальный**. Можно создать свой.

### Как создать свой стиль

1. Нажми выбор стиля → **Создать и изменить стили (Create & edit styles)**.
2. Загрузи 2–5 своих текстов (посты, письма), которые звучат «как ты». Claude сам опишет твою манеру.
3. Или опиши словами (пример ниже).
4. Назови стиль, например «Мой голос» или «Бренд кофейни».

### Пример описания стиля «Деловой и короткий»

```
Пиши как опытный предприниматель, который ценит время читателя.
Короткие предложения. Сначала суть, потом детали.
Никаких вводных фраз и вежливой воды.
Цифры и конкретика вместо общих слов.
Не больше 5 пунктов в списке.
Тон: уверенный, спокойный, на «вы».
```

### Пример стиля «Голос бренда для соцсетей»

```
Тёплый, живой, разговорный тон. Как будто пишет бариста, который знает гостей по именам.
Обращение на «вы», но без официоза. Лёгкий юмор допустим, сарказм — нет.
Предложения короткие. Один абзац — одна мысль.
Конкретные детали (запах, вкус, время) вместо прилагательных «вкусный», «отличный».
```

## 5. Личные настройки (для всех чатов)

Настройки → **Профиль** → поле «Какие личные предпочтения Claude должен учитывать в ответах». Вставь короткую версию — 5–7 строк о себе и о стиле ответов (можно взять из `custom-instructions-chatgpt.md`). Подробности — в проекте.

Также в настройках бывает **Память (Memory)** — Claude может помнить контекст прошлых чатов. Если включаешь, периодически проверяй, что он запомнил.

## Как проверить

В новом чате проекта спроси: «Перескажи коротко правила этого проекта и что ты знаешь о компании». Если всё верно — работает.
