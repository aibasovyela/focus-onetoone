# Библиотека промптов для бизнеса — 35 шаблонов

Каждый промпт собран по формуле «роль → контекст → задача → формат → ограничения». Замени всё в **[квадратных скобках]** и вставляй в ChatGPT, Claude или Gemini.

> **Совет:** сохрани 5–7 самых нужных промптов в заметки телефона или в Проект Claude / Gem в Gemini — так они всегда под рукой.

**Содержание:** Тексты и соцсети (1–6) · Отзывы и клиенты (7–9) · Переводы (10–12) · Документы (13–16) · Таблицы и цифры (17–20) · Письма (21–23) · КП и продажи (24–27) · Найм и команда (28–30) · Стратегия (31–33) · Мозговой штурм (34–35)

---

## Тексты и соцсети

### 1. Пост для Instagram / Telegram
```
Ты — SMM-редактор компании [название] ([сфера], [город]).
Аудитория: [кто читает].
Задача: напиши пост про [тема/новость/продукт]. Цель поста — [продажа / доверие / охват / приход в точку].
Формат: 3 варианта первой строки (цепляющей), затем текст до [600] знаков, в конце призыв к действию: [что сделать читателю].
Ограничения: тон [описание], на «вы», без клише «уникальный», «лучший», «качественный». Цены и условия — только эти: [данные].
```

### 2. Контент-план на месяц
```
Ты — контент-стратег. Компания: [описание]. Каналы: [Instagram/Telegram/TikTok]. Публикаций в неделю: [N].
Цели месяца: [1–3 цели]. Важные даты: [праздники, запуски, акции].
Составь контент-план на [месяц] таблицей: дата | канал | формат (пост/карусель/рилс/сторис) | тема | главная мысль | призыв.
Соотношение: 40% польза, 30% доверие (команда, кейсы, отзывы), 30% продажа. Без повторов тем.
```

### 3. Сценарий короткого видео (Reels/Shorts)
```
Напиши сценарий видео на [15–30] секунд для [продукт/услуга] компании [название].
Зритель: [кто]. Цель: [что должен сделать после просмотра].
Формат: таблица по секундам — время | что в кадре | текст на экране | что говорим голосом.
Первые 2 секунды должны остановить пролистывание. Без музыки в описании, снимаем на телефон, без сложного монтажа.
```

### 4. Описания товаров / меню
```
Ты — копирайтер для [ресторан/магазин/сервис]. Вот текущие описания: [список].
Перепиши каждое так, чтобы хотелось купить: конкретика (вкус/материал/результат), выгода для клиента, до [150] знаков.
Формат: таблица «было | стало | почему лучше (1 фраза)».
Не выдумывай состав и характеристики — только то, что есть в исходнике.
```

### 5. Текст для лендинга / сайта
```
Ты — копирайтер, который пишет продающие сайты для малого бизнеса.
Продукт: [описание]. Клиент: [портрет, его боль]. Отличие от конкурентов: [1–3 пункта]. Цена: [от …]. Доказательства: [кейсы, цифры, отзывы].
Напиши структуру и тексты блоков: первый экран (заголовок + подзаголовок + кнопка), боль клиента, решение, как это работает (3 шага), доказательства, частые вопросы (5), финальный призыв.
Простой язык, коротко, без пафоса.
```

### 6. Рерайт в тоне бренда
```
Вот описание нашего тона бренда: [описание или 2–3 примера текстов].
Перепиши этот текст в нашем тоне: [текст].
Сохрани смысл и все факты. Дай 2 варианта: короче исходника и такой же длины.
```

## Отзывы и клиенты

### 7. Ответы на отзывы (сразу пачкой)
```
Ты — управляющий [название]. Вот отзывы из [2GIS/Google/Instagram]: [отзывы].
Напиши ответ на каждый. Правила: благодарность; реакция на конкретную суть отзыва (не шаблон); на негатив — признать, извиниться без оправданий, предложить связаться: [контакт компании]. До [400] знаков, на «вы».
Не обещай скидок и компенсаций. Подпись: «[Команда …]».
```

### 8. Скрипт ответа на частые вопросы клиентов
```
Вот 10 частых вопросов наших клиентов в WhatsApp: [вопросы]. Наши условия: [доставка, оплата, гарантия, сроки].
Напиши короткие ответы-шаблоны для менеджеров: до 3 предложений, вежливо, с вопросом в конце, который двигает к покупке.
Если на вопрос нельзя ответить по нашим условиям — пометь «[уточнить у руководителя]».
```

### 9. Анализ отзывов / жалоб
```
Вот [N] отзывов клиентов за [период]: [текст или файл].
Сгруппируй по темам (сервис, качество, цена, скорость, другое). Для каждой: сколько упоминаний, 2 типичные цитаты, что исправить.
Итог: топ-3 проблемы и топ-3 сильные стороны. Только по тексту отзывов.
```

## Переводы

### 10. Деловой перевод с адаптацией
```
Переведи текст на [язык] для [кого: партнёр / клиент / госорган]. Цель текста: [что].
Не дословно — естественно для носителя, деловой тон. Термины: [список, как переводить].
После перевода — список мест, где ты изменил формулировку по смыслу, и почему.
```

### 11. Перевод + локализация для соцсетей (рус ↔ каз)
```
Адаптируй этот пост для казахоязычной аудитории: [текст].
Не дословный перевод — живой современный казахский, как говорят в [городе]. Сохрани призыв и факты. Отметь слова, в которых не уверен, чтобы я проверил с носителем.
```

### 12. Разбор документа на иностранном языке
```
Вот документ на [языке]: [текст/файл]. Я не владею этим языком.
1) Краткое содержание по-русски (5–7 пунктов). 2) Что от меня требуют / какие сроки и суммы. 3) Непонятные или подозрительные места — с цитатой оригинала и переводом.
```

## Документы

### 13. Первичный разбор договора
```
Ты — помощник юриста, объясняешь простым языком. Я — [заказчик/исполнитель/арендатор], договор [тип], сумма [X], срок [Y]. Право — [РК].
Найди пункты с рисками для меня. Формат: таблица «пункт | цитата | чем опасно | риск: высокий/средний/низкий | что предложить».
Отдельно: чего не хватает в договоре. Вопросы к юристу.
Номера статей законов не выдумывай. В конце — «это не юридическая консультация».
```
*Перед загрузкой замени ИИН, паспортные данные, реквизиты на [ИИН], [реквизиты].*

### 14. Краткая выжимка длинного документа
```
Вот документ: [файл/текст]. Я собственник, у меня 2 минуты.
Дай: суть в 3 строках; 5 ключевых пунктов; цифры, даты и суммы; что от меня требуется и до какого срока.
Только по тексту документа. Если что-то неясно — так и напиши.
```

### 15. Сравнение двух версий документа
```
Вот две версии [договора/оферты/регламента]: <версия_1>[текст]</версия_1> <версия_2>[текст]</версия_2>.
Покажи все изменения таблицей: пункт | было | стало | в чью пользу изменение. Ничего не пропускай.
```

### 16. Регламент / инструкция для сотрудников
```
Составь пошаговую инструкцию для [должность] по процессу «[название, например: открытие смены]».
Вот как это делается сейчас (сумбурно): [описание].
Формат: цель процесса; шаги нумерованным списком (кто, что, за сколько минут); частые ошибки; чек-лист в конце. Простой язык, чтобы понял новичок в первый день.
```

## Таблицы и цифры

### 17. Анализ выгрузки продаж
```
Ты — бизнес-аналитик. Вот выгрузка [продаж/заказов] за [период]: [файл].
1) Что в данных: столбцы, период, пропуски и странности. 2) Итоги и динамика по [месяцам/точкам/менеджерам]. 3) Топ-5 и анти-топ-5 [товаров/клиентов]. 4) 5 выводов. 5) 3 действия.
Считай только по файлу, для каждой цифры — как посчитано. Факт отдельно от гипотез.
```

### 18. Формула для Excel / Google Таблиц
```
У меня Google Таблица: в столбце A — [дата], B — [менеджер], C — [сумма], D — [статус].
Нужно: [что посчитать, например: сумму продаж каждого менеджера за текущий месяц только со статусом «оплачено»].
Дай готовую формулу, объясни простыми словами, как она работает, и куда её вставить.
```

### 19. Юнит-экономика / расчёт окупаемости
```
Помоги посчитать окупаемость: [проект/точка/товар]. Вложения: [X]. Средний чек: [Y]. Клиентов в день: [Z]. Себестоимость: [%/сумма]. Постоянные расходы в месяц: [аренда, ФОТ, прочее].
Посчитай по шагам: маржа с чека, прибыль в месяц, точка безубыточности, срок окупаемости. Покажи 3 сценария: плохой / средний / хороший. Таблицей.
Все расчёты — с формулами, чтобы я проверил.
```

### 20. Таблица из хаоса
```
Вот неструктурированные данные (переписка/заметки/список): [текст].
Преврати в таблицу со столбцами: [список столбцов]. Если данных для ячейки нет — оставь пусто, не придумывай. Выдай в формате, который можно вставить в Google Таблицы.
```

## Письма

### 21. Деловое письмо
```
Напиши письмо [кому] от [кого]. Ситуация: [что произошло]. Цель письма: [чего хочу добиться]. Отношения: [новый контакт / давний партнёр / конфликт].
До [150] слов, вежливо и твёрдо. Одна просьба — один призыв к действию в конце. Дай 2 варианта темы письма.
```

### 22. Письмо-напоминание о долге / оплате
```
Клиент [название] не оплатил счёт №[…] на [сумму], просрочка [N] дней. Мы работаем [срок] и хотим сохранить отношения.
Напиши 3 письма по нарастающей: 1) мягкое напоминание, 2) твёрдое с датой, 3) последнее перед претензией. Каждое до 100 слов, без угроз и эмоций.
```

### 23. Холодное письмо / сообщение партнёру
```
Я хочу предложить [компания-цель] [сотрудничество: что именно]. Что я о них знаю: [факты]. Что им даёт сотрудничество: [выгода для них].
Напиши короткое первое сообщение (до 80 слов) для [email/LinkedIn/WhatsApp]: про них, а не про нас; одна выгода; лёгкий следующий шаг (15-минутный звонок). 3 варианта.
```

## КП и продажи

### 24. Коммерческое предложение
```
Ты — эксперт по продажам B2B. Составь КП для [клиент, его сфера] на [услуга/товар].
Их задача/боль: [что знаем]. Наше решение: [что предлагаем]. Цена: [варианты/пакеты]. Сроки: [..]. Доказательства: [кейсы, цифры].
Структура: заголовок с выгодой клиента; их задача своими словами; решение; что входит; 2–3 пакета таблицей; почему мы; следующий шаг. До 1 страницы. Цены — только мои, не придумывай.
```

### 25. Скрипт звонка
```
Напиши скрипт [холодного / повторного] звонка для [продукт] клиенту [тип клиента].
Цель звонка: [встреча / демо / продажа]. Структура: приветствие и причина звонка (2 фразы), 3 вопроса на выявление потребности, короткая презентация под ответы, ответы на 5 частых возражений: [список или «придумай типичные»], закрытие на следующий шаг.
Живой разговорный язык, без «вас беспокоит».
```

### 26. Ответы на возражения
```
Мой продукт: [описание, цена]. Клиенты чаще всего говорят: [«дорого», «подумаю», «у нас уже есть поставщик», …].
Для каждого возражения: что на самом деле может стоять за ним (2–3 причины), уточняющий вопрос, 2 варианта ответа. Без давления и манипуляций.
```

### 27. Разбор проигранной сделки
```
Вот что произошло со сделкой: [история: клиент, что предлагали, что он сказал, на каком этапе отказ].
Разбери как опытный руководитель продаж: 3 вероятные причины отказа, где мы могли поступить иначе, что спросить у клиента сейчас, чтобы вернуть или узнать причину. Будь честен, не утешай.
```

## Найм и команда

### 28. Вакансия
```
Напиши вакансию [должность] для [компания, сфера, город]. Зарплата: [вилка/схема]. График: [..].
Кто нужен: [3–5 главных требований]. Чем будет заниматься: [задачи]. Почему к нам: [реальные плюсы].
Формат для [hh.kz / Instagram / Telegram]. Без клише «дружный коллектив», «стрессоустойчивость», «конкурентная зарплата».
```

### 29. Вопросы для собеседования
```
Я нанимаю [должность]. Ключевые качества: [3–4 качества]. Главные задачи на испытательный срок: [..].
Дай 10 вопросов для собеседования: для каждого — что он проверяет, хороший ответ, тревожный сигнал. Плюс 1 практическое задание на 20 минут.
```

### 30. План адаптации новичка
```
Составь план первых 14 дней для нового [должность] в [компания]. Что новичок должен знать и уметь к концу: [..].
Формат: таблица по дням — что изучает | с кем встречается | что делает сам | как проверяем. Плюс чек-лист «готов к самостоятельной работе».
```

## Стратегия

### 31. SWOT / разбор идеи
```
Ты — опытный бизнес-консультант, прямой и критичный. Идея: [описание]. Мои ресурсы: [деньги, люди, время]. Рынок: [город/страна].
Сделай: SWOT (сильные/слабые стороны, возможности, угрозы — по 3–5 пунктов); 3 главных риска и как их проверить дёшево до запуска; вердикт: делать / доработать / не делать — и почему.
Не хвали ради похвалы. Факт отдельно от предположений.
```

### 32. Анализ конкурентов
```
Мои конкуренты: [названия, что о них знаю, ссылки/публичная информация].
Сравни нас и их таблицей: продукт, цена, каналы, сильные стороны, слабые стороны, что о них пишут клиенты. Затем: 3 незанятые ниши и 3 вещи, которые стоит у них перенять.
Если данных о конкуренте нет — пометь «нет данных», не выдумывай.
```
*Для свежих данных из интернета используй режим поиска / глубокого исследования (Deep Research) или Perplexity.*

### 33. Цели и план на квартал
```
Мой бизнес: [описание]. Сейчас: [ключевые цифры]. Хочу за квартал: [цель].
Разложи цель на 3–5 измеримых результатов, для каждого — 3 действия, ответственный (роль), срок, как измеряем. Отметь, что сделать в первую неделю. Таблицей.
```

## Мозговой штурм

### 34. Генерация идей с отбором
```
Задача: [что нужно придумать — название, акцию, новый продукт, способ привлечь клиентов].
Контекст: [бизнес, аудитория, бюджет, ограничения].
1) Дай 20 разных идей — от очевидных до смелых. 2) Оцени каждую по 1–5: стоимость, скорость, эффект. 3) Выбери топ-3 и распиши первый шаг для каждой.
```

### 35. «Адвокат дьявола»
```
Вот моё решение: [описание]. Я склоняюсь его принять.
Сыграй роль жёсткого скептика: найди 7 причин, почему это может провалиться. Затем — как снизить каждый риск. В конце: что нужно проверить, прежде чем решаться.
```

