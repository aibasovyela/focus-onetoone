# Техники-усилители промпта

## Примеры (few-shot)
Показать 1–3 образца желаемого результата. Работает сильнее любого описания стиля.
```
Вот примеры, которые мне нравятся:
<пример>[текст 1]</пример>
<пример>[текст 2]</пример>
Сделай в таком же стиле: [задача]
```

## Пошаговое рассуждение
Для расчётов, выбора, стратегии.
```
Прежде чем ответить, разбери по шагам: что известно → чего не хватает → варианты → плюсы/минусы → рекомендация. Итог — в 3 строках в конце.
```
Плюс совет пользователю: включить режим рассуждения (Thinking / «Думать» / Extended thinking).

## Роль и несколько ролей
```
Оцени с позиций: финансовый директор, маркетолог, скептик-клиент. По 3 пункта. Потом общий вывод.
```

## Разметка тегами
Когда в промпте есть данные (документ, таблица, переписка), отделить их от инструкции:
```
<инструкция>…</инструкция>
<документ>…</документ>
<формат>…</формат>
```

## «Сначала задай вопросы»
```
Прежде чем делать — задай мне 5–7 вопросов, которые сильнее всего улучшат результат. Одним списком. Жди ответов.
```

## Опора на источник
```
Отвечай только по данным выше. Если ответа нет — напиши «в данных этого нет». Для каждого вывода — цитата.
```

## Самопроверка
```
Проверь свой ответ: выдуманные факты? всё ли из задачи сделано? что можно сократить? Дай исправленную версию.
```

## Итерации (фразы для доработки)
- «Короче в 2 раза.»
- «Вариант 2, но тон теплее.»
- «Убери общие слова, добавь конкретику.»
- «Что здесь слабее всего? Исправь.»
- «Собери итоговый промпт, который сразу дал бы этот результат.»
