# Скиллы для Claude: 7 навыков для предпринимателя

**Скилл (Skill)** — папка с инструкцией (файл `SKILL.md`), которая учит Claude делать конкретную работу по твоим правилам. Claude сам понимает, когда скилл нужен: по описанию в начале файла. Тебе не нужно каждый раз объяснять, как разбирать договор или писать КП: один раз установил, и дальше работает.

Скиллы сделаны в официальном формате Anthropic: в каждой папке есть `SKILL.md` с шапкой (`name` — название, `description` — когда включать) и, где нужно, папка `references/` с шаблонами.

## Как установить в Claude (сайт или приложение)

1. Скачай zip нужного скилла (внутри архива лежит папка `<название>/SKILL.md`). **Не распаковывай.**
2. Открой Claude → **Настройки (Settings)** → **Возможности (Capabilities)**.
3. Если есть переключатель выполнения кода и создания файлов (Code execution / File creation), включи его: скиллам он нужен.
4. Найди раздел **Skills** → **Загрузить скилл (Upload skill)** → выбери zip.
5. Проверь, что скилл включён (переключатель рядом с названием).
6. В новом чате попроси, например: «Разбери этот договор». Claude сам подхватит doc-reviewer. Можно и прямо: «Используй скилл kp-builder».

> **Точные названия пунктов меню могут отличаться** в зависимости от версии и тарифа: раздел может называться «Скиллы», «Навыки», лежать в «Возможностях» или в «Функциях». Ищи по смыслу. На некоторых тарифах скиллы может включать только администратор команды. Официальная справка: https://support.claude.com/en/articles/12512180-using-skills-in-claude

## Как установить в Claude Code (агент на компьютере)

Скопируй папку скилла (не zip) в одну из папок:

- `~/.claude/skills/<название>/SKILL.md`: скилл доступен во всех проектах;
- `<папка проекта>/.claude/skills/<название>/SKILL.md`: только в этом проекте.

Перезапуск не обязателен, но если скилл не виден, начни новую сессию. Документация: https://code.claude.com/docs/en/skills

## Как подстроить скилл под себя

Скилл — это обычный текст. Открой `SKILL.md` в любом редакторе и поправь:

- **description** (в шапке) отвечает за то, *когда* Claude включает скилл. Добавь свои слова-триггеры.
- **Тело файла** отвечает за то, *как* Claude работает. Впиши свои правила, стоп-слова, формат.
- **references/**: положи туда свой прайс, примеры текстов, шаблон договора. Скилл будет на них опираться.

После правки снова упакуй папку в zip (так, чтобы внутри архива была папка с `SKILL.md`) и загрузи заново.

**Правило студии:** если одну и ту же задачу ты делаешь больше трёх раз, сделай для неё скилл. Попроси Claude: «Помоги сделать скилл для [задача]». У Anthropic для этого есть официальный скилл **skill-creator**.
