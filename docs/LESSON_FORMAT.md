## lesson.md — тело урока
Обычный markdown: # не использовать; разделы — "## Заголовок" (каждый ## попадает в оглавление), "### Подзаголовок",
абзацы, списки "- " и "1. ", **жирный**, *курсив*, `код`, [ссылка](https://...), > цитата, ---,
блоки ``` (копируемые промпты; на английском для генерации картинок/видео), таблицы GFM:
| Колонка | Колонка |
|---|---|
| a | b |

Спец-блоки (каждый открывается и закрывается строкой ::: ):
:::lead
Крупный лид-абзац в начале раздела.
:::
:::tip Заголовок        (виды: tip — совет, warn — важно, example — пример, note — заметка)
Текст выноски, можно списки и **жирный**.
:::
:::diagram file-name Подпись под диаграммой
:::                      → вставляет materials/module-N/diagrams/file-name.svg
:::steps
1. Шаг — описание
2. Шаг — описание
:::                      → крупные нумерованные шаги-карточки
:::prompt Название промпта
текст промпта (копируемый блок с заголовком)
:::

## diagrams/*.svg — inline SVG
- viewBox шириной 360 (mobile-first), высота по содержимому; без width/height атрибутов (или width="100%").
- Только <svg>, <g>, <rect>, <circle>, <ellipse>, <line>, <path>, <polyline>, <polygon>, <text>, <tspan>, <defs>, <linearGradient>, <radialGradient>, <stop>, <marker>. Без <script>, <foreignObject>, <image>, внешних ссылок, on*-атрибутов.
- Цвета бренда «Лаванда»: ink #0F1112, paper #EEEAE2, paper2 #F7F5F0, line #D6D0C6, violet #8B5CF6, violet-ink #5B33C9, lavender #D2C2FF, peach #FFB59A, deep #24124A, end #0C0718, mute #8C8880, text2 #45433F.
- Шрифты: font-family="Unbounded, Arial, sans-serif" для заголовков, "Golos Text, Arial, sans-serif" для текста, "IBM Plex Mono, monospace" для меток. Размер текста не меньше 11 (при ширине 360), подписи короткие, по-русски. Фон прозрачный или paper2; скругления rx 10-14.
- Каждая диаграмма — 1 идея, читается на телефоне без зума.
