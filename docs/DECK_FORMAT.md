# Урок-слайды (materials/module-N/deck.json)

Если в модуле есть deck.json — урок показывается плеером слайдов (← → / свайп), иначе старый лонгрид из lesson.md.
Принцип: 1 слайд = 1 мысль, читается на телефоне без прокрутки (390×844 и 390×664 — iPhone с панелями Safari). Текст слайда ≤ 45 слов. Визуал на каждом втором слайде.
Не влезает — дели на два слайда (пример: «Частые ошибки · 1 из 3»), а не уменьшай шрифт. Эмодзи в заголовках глав не используем.

```json
{
  "version": 1,
  "chapters": [
    { "id": "think", "title": "Как думает нейросеть", "slides": [ /* слайды */ ] }
  ]
}
```

## Типы слайдов (поле "type")
Общие поля: "title" (короткий, ≤ 7 слов), "kicker" (метка сверху, необязательно), "note" (мелкая сноска, необязательно).
Текст в полях "text"/"items" поддерживает **жирный**, *курсив*, `код`. Без markdown-заголовков.

- cover — обложка главы: { "type":"cover", "title", "text", "image":"cover-think.webp" }  (картинка во весь слайд, текст поверх снизу)
- text — { "title", "text" (1-3 коротких абзаца, разделитель \n\n) , "image"? , "diagram"? }
- bullets — { "title", "items": ["…", "…"] (3-5 пунктов, каждый ≤ 14 слов), "icon"? : "✓|→|✕" }
- diagram — { "title", "diagram":"file-name" (materials/module-N/diagrams/file-name.svg), "caption" }
- image — { "title", "image":"file.webp", "caption", "prompt"? (английский промпт, которым сделана картинка — кнопка «Промпт этой картинки» открывает панель с кнопкой «Скопировать») }
- chat — пример диалога: { "title", "app":"ChatGPT|Claude|Gemini", "messages":[ {"role":"user","text":"…"}, {"role":"ai","text":"…"} ], "caption"? }
- compare — до/после: { "title", "bad": {"label":"Плохо","text":"…"}, "good": {"label":"Хорошо","text":"…"}, "caption"? }  (переключатель-таб «Было / Стало»)
- stat — крупная цифра: { "value":"128 000", "unit":"токенов", "title", "text" }
- steps — { "title", "items":[ {"title":"…","text":"…"} ] } (до 5)
- cards — переворачиваемые карточки: { "title", "items":[ {"front":"…","back":"…"} ] } (2-6, тап = переворот)
- quiz — { "title"(вопрос), "options":["…","…","…"], "answer": 1 (индекс верного), "explain":"…" }
- builder — конструктор промпта: { "title", "parts":[ {"label":"Роль","text":"…","color":"violet"} ], "caption" } (тапы добавляют части, внизу собирается итоговый промпт + «Скопировать»)
- prompt — копируемый промпт: { "title", "text":"…", "caption"? }
- table — сравнение: { "title", "columns":["","ChatGPT","Claude","Gemini"], "rows":[["Тексты","…","…","…"]] } (на телефоне: 3+ колонок данных — переключатель колонок, иначе карточки по строкам; карточек ≤ 3 на слайд)
- checklist — { "title", "items":[…] } (галочки сохраняются в localStorage)
- links — { "title", "items":[ {"label":"…","url":"https://…","text":"…"} ], "feature"? : true (одна крупная ссылка в акценте модуля) }
- gallery — готовые примеры: { "title", "items":[ {"title":"…","model":"Nano Banana 2","image":"ex-01.webp","prompt":"…","source":"https://higgsfield.ai/…","video"?:"https://….mp4","ref"?:"из фото"} ], "caption"? }
  (3-4 карточки на слайд: сетка на широком слайде, листание на телефоне; у карточки «Скопировать промпт», «Весь промпт», ссылка на оригинал.
  Только публичные работы с опубликованным промптом — промпт не придумываем; для видео image = постер, video = оригинал)

## meta.json — оформление модуля
- "card": "cover-….webp" — обложка модуля на карточке маршрута (стиль модуля: docs/MODULE_STYLES.md).
- "useful": [ {"kicker":"…","label":"…","url":"https://…","text":"…"} | {"label":"…","chapter":"<id главы>","text":"…"} ] — блок «Полезное» на странице модуля
  (url — внешняя ссылка, chapter — открывает урок на этой главе).

## Медиа
Картинки: frontend/media/module-N/<file>.webp (публичные, ≤ 250 КБ, 1080 по ширине). В deck.json — только имя файла.
Диаграммы: как в LESSON_FORMAT.md (SVG, viewBox ширина 360, бренд «Лаванда»).

## Проверка перед выкладкой
`scripts/deck_check.py` (Playwright): проходит все слайды и ищет вертикальное переполнение, обрезанные блоки,
горизонтальную прокрутку страницы, незагруженные картинки, мелкий текст в SVG (< 10.5 px на экране), ошибки консоли.
```
PORT=3010 node backend/server.js &
PIN=<демо-пин> python3 scripts/deck_check.py all        # телефон 390×844 + десктоп 1440×900
PIN=<демо-пин> python3 scripts/deck_check.py safari     # 390×664, также se / android
```
