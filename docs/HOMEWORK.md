# Сдача ДЗ: текст, ссылка, файлы, уведомление ведущему

## Ученик
Кнопка «Сдать ДЗ» на странице блока → шторка (`js/homework.js`, `css/homework.css`):
- «Что получилось» — текст (до 20 000 символов);
- «Ссылка на результат» — одна ссылка http/https (без протокола — допишем `https://`);
- «Файлы» — до 5 штук по 20 МБ: картинки (JPG, PNG, GIF, WEBP, HEIC), PDF, Word/Excel/PowerPoint (новые и старые), TXT/MD/CSV.
Нужно хоть что-то одно. Файлы грузятся сразу при выборе (полоска прогресса), «Отправить» ждёт окончания загрузки.
После сдачи в блоке «Как сдать» — «Отправлено <дата, время>», ссылка и превью файлов.

## Ведущий (сессия по пину из `hostPins`)
`#host` → под планом созвонов выбранного ученика — «Сданные ДЗ» (новые сверху): блок, время (Алматы), текст, ссылка,
превью картинок (клик — на весь экран, «Скачать»), документы — скачиванием. `#host/<id ученика>` открывает сразу его.

## API (`backend/routes/homework.js`, `backend/lib/uploads.js`)
- `POST /api/homework/upload` — тело = сам файл, `Content-Type` = тип, `X-File-Name` = `encodeURIComponent(имя)` → `{ file: { id, name, mime, size, image } }`.
  Тип определяется по сигнатуре содержимого (не по заголовку); ZIP/OLE (docx/xlsx/pptx, doc/xls/ppt) — сигнатура + расширение;
  текст — только валидный UTF-8 без NUL. Заголовок `Content-Type` тоже из белого списка (или пустой/octet-stream). >20 МБ → 413.
- `DELETE /api/homework/upload/:id` — убрать свой ещё не сданный файл.
- `POST /api/homework/submit` `{ moduleId, content?, link?, files?: [id] }` — файлы должны быть свои и не сданные.
- `GET /api/homework/:moduleId` — задание + свои сдачи (у файлов `url`).
- `GET /api/homework/files/:studentId/:id[?inline=1]` — файл: только сам ученик или ведущий (иначе 403, без входа 401).
  `Content-Disposition` attachment/inline с именем, `nosniff`, `CSP sandbox`, `no-store`.
- `GET /api/homework/host/all` — все сдачи всех учеников (только ведущий).

Хранение — вне `frontend/`: `$FOCUS_UPLOAD_DIR/<studentId>/<uuid>` + `<uuid>.json` (имя, тип, размер, `hwId`).
Прод: `/var/lib/focus-onetoone/uploads` (www-data, 750; файлы 640). Без переменной — `<db>/uploads`.
Несданные файлы старше суток удаляются при следующей загрузке ученика; не больше 20 несданных на ученика.

## Уведомление (`backend/lib/notify.js`)
После ответа ученику (асинхронно, таймаут 20 с) бот агента fokus @Focusai_yelumio_bot пишет ведущему:
блок, ученик, время (Алматы), текст ≤300 символов, ссылка, «Открыть в кабинете» (`#host/<id>`), затем сами файлы
ответом на сообщение (JPG/PNG/WEBP ≤10 МБ — фото, остальное — документом). Ошибка Telegram сдачу не ломает — только строка
`[notify] …` в журнале службы, токен вырезается.
Переменные из EnvironmentFile службы (`/etc/focus-onetoone/tg.env`, 600 root): `TG_BOT_TOKEN`, `TG_CHAT_ID`.
В коде и репо токена нет. Нет переменных — уведомления просто не шлются. `NOTIFY_TAG=ТЕСТ` — пометка для стенда.
